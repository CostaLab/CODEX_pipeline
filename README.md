# CODEX_pipeline

[![License: MIT](https://shields.io)](https://opensource.org)
[![Python 3.8+](https://shields.io)](https://python.org)

This repository contains a collection of scripts developed by Mayra Ruiz from the [Costa Lab](https://github.com/CostaLab) for the analysis and processing of high-dimensional **CODEX** (Co-detection by Indexing) multiplexed imaging data.

---

## 🚀 Features

- **Image Registration & Preprocessing**: Tools to process raw cyclic imaging data.
- **Nucleus & Cell Segmentation**: Robust segmentation scripts to extract cellular boundaries.
- **Single-Cell Feature Extraction**: Quantitative extraction of marker expression levels (e.g., average brightness) and spatial coordinates.
- **Data integration**: Integration of data from different images for comparative analyses
- **Downstream Visualization**: Data visualization and conversion of multiplexed data into h5ad format.
